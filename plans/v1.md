# Plan v1 — Analysis Switchyard for T2 Timer

## Decisions Made
- Task type is carried in the Jives comment stream as `"Trial N: Task <name>"`
- Three task types: `Fixation task`, `Visual Saccade Task`, `Time discrimination task`
- `plotJivesPsychometrics` serves as the existing plot function for Time discrimination
- Two new stub plot functions created for Fixation and Visual Saccade tasks
- Switchyard reads `trials(end).task_type` to dispatch; falls back to warning if unknown
- Both `jivesBRGui.m` and `jivesBROnline.m` updated to call the switchyard

## Files Touched
1. `getJivesData.m` — add `task_type` field and parse `"Task ..."` event
2. `jivesAnalysisSwitchyard.m` — new: reads task_type, dispatches to plot function
3. `plotJivesFixation.m` — new stub plot function for Fixation task
4. `plotJivesVisualSaccade.m` — new stub plot function for Visual Saccade task
5. `jivesBRGui.m` — T2 timer calls switchyard instead of plotJivesPsychometrics
6. `jivesBROnline.m` — same T2 update
